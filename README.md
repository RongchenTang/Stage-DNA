# Stage DNA｜音乐剧角色探索

面向课堂的 21 项趣味兴趣探索网页：12 项幕后工作兴趣、6 项台前表达风格、3 项演出意愿。结果保留原始计数和并列，不作为心理诊断或能力鉴定；所有学生都参与台前演出，具体舞台人物由剧本、协商和试演确定。

网页为无需构建的静态站点，`index.html` 位于仓库根目录。若 GitHub Pages 已设置为从 `main` 分支根目录发布，访问地址为：<https://rongchentang.github.io/Stage-DNA/>。

## 使用与数据

- 手机逐题作答，刷新后可恢复；结果页可保存角色卡 PNG 和个人组内分工记录 PNG。
- 六位人物是透明黑金服装版本，四种卡片氛围中，戏剧张力型使用橙色到蓝色渐变。
- 答案和学生填写的称呼、小组及任务仅保存在其当前浏览器的 `localStorage`。网站没有账号、云端收集或教师汇总后台。需要汇总时，请学生自行提交保存的图片。
- 可直接部署为静态网页；本地预览需使用 HTTP 服务，不能保证双击 `index.html` 后浏览器仍能读取题库。

## 文件

- `data/questions.json`：原交接题库，内容未经修改。
- `assets/characters-v2/`：六张透明人物 WebP。
- `score.mjs`、`state.mjs`：计分、并列及答题状态。
- `view.mjs`、`styles.css`、`card.mjs`、`assignment.mjs`、`app.mjs`：页面与两类 PNG 导出。

GitHub Pages 的 `github.io` 地址在中国大陆不同网络下可能出现无法访问或加载缓慢。正式课堂使用前，应在学生实际使用的校园网络和手机运营商网络测试；代码上传 GitHub 本身不能保证无需翻墙访问。
